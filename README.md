# Ksumana Adhikari — Blogger Theme

A responsive personal-brand homepage and Blogger theme for **ksumanadhikari.com.np**.

## Direction

Personal brand + learning media + digital services hub. The homepage introduces the person and their interests first; the latest Blogger articles appear further down the page.

## Included

- Personal introduction / hero with profile-photo placeholder
- About, values, interests, learning, and collaboration sections
- Technology, education, business, and law interest cards
- Learning resources and services sections
- YouTube and podcast embed placeholders configured in JavaScript
- Social/contact area
- Lower homepage journal powered by Blogger's native Blog widget
- Responsive navigation and layouts
- External CSS and JavaScript served from jsDelivr

## Repository layout

- `theme/blogger-theme.xml` — Blogger template
- `assets/css/site.css` — complete visual styling
- `assets/js/site.js` — navigation and media configuration
- `docs/SETUP.md` — installation and customization

## Install

See [docs/SETUP.md](docs/SETUP.md). Back up your current Blogger theme before replacing it.

## CDN

- CSS: https://cdn.jsdelivr.net/gh/crazysuman99/ksumanadhikari-theme@main/assets/css/site.css
- JS: https://cdn.jsdelivr.net/gh/crazysuman99/ksumanadhikari-theme@main/assets/js/site.js

Replace sample links, contact details, profile photo, YouTube ID, and podcast embed URL before publishing.
