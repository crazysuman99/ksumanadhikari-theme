# Ksumana Adhikari — Blogger Theme

A responsive, Blogger-managed personal brand website for **ksumanadhikari.com.np**.

## Direction

Personal brand + learning media + digital services hub. The homepage introduces the person and their interests first; latest articles appear further down.

## Included

- Editable hero and content sections through Blogger Layout Text gadgets
- Editable profile photo through a Blogger Image gadget
- Automatic latest posts from the connected Blogger blog
- About, interests, learning, services and contact sections
- Supplied social profile links and official contact email
- Spotify podcast player embed
- YouTube channel link and an editable embed gadget zone
- Responsive navigation and layout
- External CSS and JavaScript served from jsDelivr

## Repository layout

- `theme/blogger-theme.xml` — Blogger template and gadget zones
- `assets/css/site.css` — visual styling
- `assets/js/site.js` — mobile navigation
- `docs/SETUP.md` — installation and editing guide

## Install

See [docs/SETUP.md](docs/SETUP.md). Back up the current Blogger theme before replacing it.

## CDN

- CSS: https://cdn.jsdelivr.net/gh/crazysuman99/ksumanadhikari-theme@main/assets/css/site.css
- JS: https://cdn.jsdelivr.net/gh/crazysuman99/ksumanadhikari-theme@main/assets/js/site.js

Normal profile photo, text, links, and post updates are intended to happen through Blogger dashboard, not by editing theme source.
